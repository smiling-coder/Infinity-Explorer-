Infinity Explorer is an interactive 3D website with no normal pages. You travel through the Solar System by scrolling, and each planet opens its own information.



# 🌌 Infinity Explorer — A Cinematic 3D Space Journey

> Explore the universe, discover fascinating planets, and experience the wonders of space through an immersive digital journey.

**Infinity Explorer** is a space exploration website designed to make learning about our solar system more engaging through interactive visuals, planetary information, animations, and a cinematic scrolling experience.

The project combines modern web technologies with a space-inspired design to create an exciting journey through the universe.

---

## 🚀 Project Overview

Infinity Explorer aims to transform the traditional way of exploring planetary information into a visually engaging experience.

Visitors can explore the solar system, learn interesting facts about planets, and experience a space-themed interface featuring animated elements and interactive content.

### ✨ Key Highlights

- 🌌 Space-inspired user interface
- 🪐 Information about the eight planets
- 🚀 Cinematic scrolling experience
- 🎥 3D planetary visualizations
- ⭐ Animated space backgrounds and stars
- 🔭 Interactive planetary exploration
- 📱 Responsive website design
- ⚡ Smooth animations and transitions
- 🌍 Educational content about our solar system
- 🔄 Automated deployment using GitHub Actions

---

## 🎯 Project Objectives

- Make space science more accessible and engaging.
- Present planetary information through an interactive interface.
- Explore 3D graphics and animation using web technologies.
- Create a visually immersive scrolling experience.
- Develop practical skills in frontend development.

## 🪐 Explore the Solar System

Infinity Explorer introduces visitors to the eight planets of our solar system.

| Planet | Description |
|---|---|
| ☿️ Mercury | The smallest planet and the closest to the Sun. |
| ♀️ Venus | A planet with an extremely hot surface and dense atmosphere. |
| 🌍 Earth | Our home planet, known for its liquid surface water and life. |
| 🔴 Mars | The red planet, a major target for planetary exploration. |
| ♃ Jupiter | The largest planet in our solar system. |
| 🪐 Saturn | A gas giant famous for its spectacular ring system. |
| ♅ Uranus | An ice giant that rotates on its side relative to its orbit. |
| ♆ Neptune | A distant ice giant with powerful winds. |

## 🛠️ Technologies Used

### Frontend
- **HTML5** — Website structure and content.
- **CSS3** — Styling, responsive layouts, and visual effects.
- **JavaScript** — Interactivity and animation logic.

### 3D Graphics and Animation
- **Three.js** — Real-time 3D graphics in the browser.
- **GSAP** — Animation timelines and smooth transitions.
- **GSAP ScrollTrigger** — Scroll-controlled animation effects.

### Development and Deployment
- **Git** — Version control.
- **GitHub** — Source code hosting.
- **GitHub Pages** — Static website hosting.
- **GitHub Actions** — Automated deployment workflow.

*Some features depend on the successful integration and configuration of their respective libraries.*
